# ADR-0001: Record architecture decisions

- Status: Proposed
- Date: 2026-10-18

## Context
This is a portfolio project. Reviewers need to see why decisions were made, not only what was built.

## Decision
Significant technical decisions are recorded as numbered ADRs in `docs/decisions/`. An ADR is never edited after acceptance except for status changes. A change of direction gets a new ADR that supersedes the old one.

## Consequences
There is a small writing overhead per decision, in exchange for a clear audit trail. Documents link to ADRs instead of repeating the rationale.

## Alternatives considered
Decisions recorded only in commit messages or a wiki: harder to find and review.
